# Manufacturing outputs

These Gerber and Excellon drill files were generated from the KiCad 10 PCB and visually reviewed in KiCad Gerber Viewer on 18 July 2026.

## Included files

- `Ignition_Coil_Detector-F_Cu.gtl` — front copper
- `Ignition_Coil_Detector-B_Cu.gbl` — back copper
- `Ignition_Coil_Detector-F_Mask.gts` — front solder mask
- `Ignition_Coil_Detector-B_Mask.gbs` — back solder mask
- `Ignition_Coil_Detector-F_Silkscreen.gto` — front silkscreen
- `Ignition_Coil_Detector-Edge_Cuts.gm1` — board outline
- `Ignition_Coil_Detector-PTH.drl` — plated holes
- `Ignition_Coil_Detector-NPTH.drl` — non-plated mounting holes
- `Ignition_Coil_Detector-job.gbrjob` — Gerber job description

For fabrication, ZIP the nine files above together. Re-export and review the outputs if the KiCad PCB is changed.
