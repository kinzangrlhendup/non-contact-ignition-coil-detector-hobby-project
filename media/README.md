# Media

## KiCad 3D board preview

`kicad-3d-board-preview.mp4` is a 15.8-second H.264 preview of the current KiCad 3D board model.

For efficient GitHub viewing, the supplied 1882×962 H.264/AAC recording was converted to a 960×490 H.264 preview without audio. The circuit and board content were not altered.
